# Working on the app

The browser extension adds the archive button. A Python service on `127.0.0.1:18765` downloads the chosen posts and serves the local interface.

The shared extension code is in `chrome-extension/`. Browser packages are generated by `build_extensions.py`. The local UI lives in `manual_ui/`; `archive_server.py` connects it to the archive worker. Storage and verified copying are handled by `app_paths.py` and `storage_manager.py`.

## Run from source

Use Python 3.12. Create a virtual environment, then install `requirements-dev.txt` and run `python archive_server.py`. Install the browser bridge with `python install_native_host.py` if you want to use the extension. Load the extension as described in [INSTALL.md](INSTALL.md).

## Tests

```sh
python -m pytest tests
```

Python tests use temporary archives and synthetic posts. Browser UI tests use Playwright and Node.js. Tests named `test_dashboard_ui.cjs`, `test_storage_ui.cjs` and `test_category_suggestions.cjs` can run with mocked data; set `PLAYWRIGHT_PATH` and `CHROME_PATH` to your installed Playwright module and Chromium executable. Some older browser integration tests require a local service; read their setup before running them.

## Build

```sh
python build_extensions.py --browser all --output dist/extensions
python build_distribution.py --output dist/sources
python -m pip install pyinstaller
python build_exe.py --output dist/windows-release
```

Choose new output folders for each build. Build the executable on the operating system you intend to distribute. There is no prebuilt macOS or Safari app in this release.

Only code, default configuration and extension assets belong in a release. Personal archives, cookies, browser profiles and installed native manifests are excluded. Third-party components retain their own licenses; see [THIRD_PARTY.md](THIRD_PARTY.md).

The legacy `test_results_ui.cjs` exports from a real local archive. It is disabled unless you explicitly set `ALLOW_ARCHIVE_EXPORT_TEST=1` and `RESULTS_TEST_DIR`. `test_extension.cjs` needs port 18765 free for its synthetic bridge.
